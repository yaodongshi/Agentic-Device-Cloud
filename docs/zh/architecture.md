# 架构

> ADC V1.0 采用"控制面/数据面轻拆分"：10 个模块、四层结构，所有客户端统一收敛到唯一的 API 网关之后。本页是对 `design/30`（HLD）系统设计的摘要。

## 模块职责

| 模块 | 层 | 版别 | V1.0 职责 |
| --- | --- | --- | --- |
| M1 Admin API | 控制面 | EE | 租户管理、设备台账（登记/吊销/凭证轮转）、Agent API Key 签发、工具风险等级配置、审批流配置、审计查询、用量查询 |
| M2 控制台 | 控制面 | EE | 上述能力的 Vue 3 管理界面；审批与审计浏览；i18n 就绪 |
| M3 设备连接器 | 数据面 | CE | Legacy Bridge WSS 接入、HMAC 设备鉴权、会话管理、工具目录同步、路由索引（Valkey TTL）、工具调用下发（本地直连快速路径，跨节点经消息抽象接口） |
| M4 Agent API | 数据面 | CE | API Key 认证与租户强绑定、工具聚合、风险判定（V1.0 读 DB risk_level）、HITL 转交、同步调用超时（15 秒）、三维度限流、审计事件发布 |
| M5 审批服务 | 数据面 | CE（单级）/ EE（多级） | HITL 工单状态机（PostgreSQL）、企微/钉钉卡片、回调验签、过期 fail-safe（默认拒绝）、挂起调用唤醒 |
| M6 审计服务 | 数据面 | CE | 结构化审计事件缓冲落 PG 分区表；供控制台查询 |
| M7 LLM 网关旁路 | 旁路 | CE 底座 / EE 计量 | litellm 模型代理、Token 计量打点；可选部署，V1.0 不在设备调用主链路 |
| M8 边缘 SDK | 边缘 | SDK | wire 协议 v1、WSS 客户端（TLS、退避重连）、HMAC 签名、工具注册 API、本地队列缓存（不自动重放） |
| M9 Python Agent 面 | Agent 面 | CE | FastAPI/uvicorn。V1.0：评测工具链与开发脚本；V1.5 起：LLM 网关编排、Agent 编排、A2A Agent Card |
| M10 统一 API 网关 | 网关层 | CE | 唯一入口，按路径前缀路由、统一 TLS 终结、会话校验透传、限流、契约校验 |

## 依赖规则

1. **单向依赖、禁止成环**：上图箭头方向即唯一允许的调用方向。
2. **外部客户端只依赖 M10**：前端与 Agent 只配置一个网关地址，禁止直连业务服务或数据库。
3. **控制面与数据面互不直接调用**：共享数据一律经 PostgreSQL 收敛。
4. **业务模块只依赖消息抽象接口**：禁止直接使用 Valkey 客户端命令，阶段 2 换 NATS JetStream 不改业务代码。
5. **LLM 网关旁路不拦截主链路**：其故障不影响设备调用。
6. **控制台是 M1 的唯一 Web 消费者**：审计查询经 M6 或 M1 委托。
7. **M9 与数据面进程边界隔离**：仅经内网 HTTP 与消息总线交互，对外一律经网关。

## 关键数据流

### 设备接入流（Legacy Bridge）

```text
设备(SDK)        M3 连接器           Valkey             PostgreSQL
   |  WSS 握手（TLS、Origin 白名单）  |                    |
   |---------------------->|         |                    |
   |  HMAC 鉴权（DB 加载凭证、       |                    |
   |  nonce + timestamp 校验）       |                    |
   |---------------------->|         |                    |
   |<-----会话建立---------|         |                    |
   |  tools/list（带版本） |         |                    |
   |---------------------->|         |                    |
   |<-----工具目录（含 risk_level）--|                    |
   |  路由索引：设备 -> 节点，TTL 90 秒、每 30 秒续期      |
   |---------------------->|-------->|                    |
   |  工具目录异步同步台账  |---------------->|            |
   |  tools/list_changed（增量）     |         |           |
   |  断开 -> 连接器主动清理索引      |         |           |
```

### 工具调用与 HITL 审批流

```text
Agent      M4 Agent API      M5 审批       Valkey     M3 连接器     设备
  | tools/call |               |             |            |          |
  |----------->| API Key 认证 + 租户绑定     |            |          |
  |            | 风险判定：risk_level < 2 -> 直路由      |            |
  |            | risk_level >= 2 -> 创建 PG 工单（PENDING）            |
  |            | 推送 IM 卡片（签名回调、双语）            |          |
  |<-- 202 pending_hitl + ticket_id |        |            |          |
  |  审批人点击签名 URL + OAuth 身份   |        |            |          |
  |            | CAS 原子更新 PENDING -> APPROVED/REJECTED             |
  |            | 发布唤醒事件 ---------->|      |            |          |
  |            | 路由：本地直连 / 跨节点经 Valkey       |            |
  |            |--------------------------------------------->|       |
  |            |                                             |--调用-->|
  |            |<--------------------------------------------|<--结果--|
  |<-- 200 结果 | 审计事件（异步）-> 缓冲 -> M6 落库 PG        |        |
```

### 审计流

```text
业务模块      Valkey（List 缓冲）      M6 审计服务      PostgreSQL
  结构化事件 -> RPUSH adc:audit:buffer
                BLPOP 批量消费 -> 校验 -> 批量写入分区表
  （追加式、不可修改、留存 180 天以上）
```

## 关键技术决策（V1.0 生效）

| 决策 | 选择 | V1.0 落地边界 |
| --- | --- | --- |
| ADR-01 服务拆分 | 控制面/数据面轻拆分 | 共用 `ce/` 代码库，独立进程装配 |
| ADR-02 消息通道 | NATS JetStream（终态） | V1.0 经消息抽象接口使用 Valkey 适配器 |
| ADR-04 设备凭证 | 先 HMAC + nonce + timestamp，终态 mTLS | Legacy Bridge 全量落地 |
| ADR-05 HITL 状态 | PG 状态机 + Valkey 唤醒 | 工单持久化、不可抵赖 |
| ADR-07 风险引擎 | OPA（终态） | V1.0 读 DB risk_level，RiskPolicy 接口过渡 |
| ADR-12 仓库许可 | monorepo：core-sdk/ Apache-2.0、ce/ LGPL-3.0、ee/ 商业 | seam 接口装配 EE |
| ADR-13 存储 | Valkey 替代 Redis（许可原因） | V1.0 部署栈即 Valkey 8 |
| ADR-15 设备接入 | 原生 MCP Streamable HTTP 为主，WSS 桥接 B 类 | V1.0 仅 Legacy Bridge；A 类 V1.5 |
| ADR-19 统一网关 | Go 网关承担路由、鉴权透传、限流、契约校验 | 前端无感原则，只配置一个网关地址 |
| ADR-20 双语言 | Go 数据面 + Python Agent 面 | V1.0 交付 Python 评测工具链；完整 Agent 面 V1.5 起 |

## 版本边界

| 能力 | V1.0 | V1.5 |
| --- | --- | --- |
| 设备接入 | B 类 Legacy Bridge（WSS） | A 类原生 MCP 设备，OAuth 2.1 绑定 |
| Agent API | MCP 兼容形态，无握手 | 标准 MCP Streamable HTTP + initialize |

| Agent 面 | 评测工具链 | LLM 网关、四 Agent 编排、A2A Agent Card |

## 安全模型摘要

六条信任边界在 V1.0 全部设防：设备（WSS + TLS + HMAC 挑战）、Agent（HTTPS + API Key + 租户绑定）、审批人回调（URL 签名 + 一次性 HMAC 回调 + OAuth 身份）、节点间（Valkey ACL + TLS + 消息签名）、通知渠道（webhook 密钥环境注入）、管理面（HTTPS + 会话 + RBAC）。SEC-01 至 SEC-25 详见 `doc/05`，具体请求头与错误码契约见 API 参考。
