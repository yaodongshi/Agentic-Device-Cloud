## 1. 引言

### 1.1 目的

本文档将 doc/03 PRD 中 V1.0 范围内的功能需求（FR）与非功能需求（NFR）细化为可被开发、测试直接引用的工程规格：每条 FR 给出输入/处理/输出与可验证的业务规则（BR 编号），每个核心场景给出用例规格（UC 编号），并建立 FR、UC 与设计文档（design/32、design/33）的追踪矩阵。本 SRS 不改变 doc/03 的 FR/NFR 编号与结论，仅做细化与可测化。

### 1.2 范围（V1.0）

- 功能范围：FR-001~010、FR-013、FR-014、FR-018~020 全量；其中 FR-005 为生产化单级审批（工单 PG 持久化、回调签名、真实审批人身份）；FR-007 仅交付单级审批策略配置子集。
- 非功能范围：NFR-001/003/004/006 达标；NFR-002 按 1000 台在线设备验证（1 万在线设备压测为 V1.5 门禁）。
- 非目标：沿用 doc/03 第 1.3 节，其中与本 SRS 直接相关的三条：免审白名单 V1.0 不做；控制台 UI 仅中文首发（多语言经 FR-023 于 V1.5 交付）；等保 2.0 三级测评在 V1.5 前通过（V1.0 完成差距分析）。

### 1.3 术语定义

| 术语 | 定义 |
|------|------|
| MCP | Model Context Protocol，模型上下文协议（2025-06-18 版），tools/list 与 tools/call 为设备场景核心契约；平台 Agent 面采用 Streamable HTTP 传输（ADR-03） |
| A2A | Agent2Agent 协议，标准化 Agent 间协作委派；平台 V1.5 发布 Agent Card 接受外部委派（FR-022，方案 A 决策前移），V1.0 仅预留接口不交付 |
| HITL | Human-in-the-loop，人工审批机制：风险等级不低于 2 的工具调用被拦截，经企微/钉钉卡片由审批人同意或拒绝 |
| WSS | WebSocket Secure，TLS 之上的 WebSocket；B 类 SDK 桥接设备反向接入通道 |
| Legacy Bridge | 原 WSS 反向隧道自 V1.5 起的定位：仅服务 B 类无原生 MCP Server 运行时的设备（ADR-15）；V1.0 设备接入以该通道为主 |
| 租户 | 平台多租户隔离单位，拥有独立命名空间（设备、工具、Agent、审计数据互不可见） |
| 风险等级 | 工具的可配置属性：0 只读 / 1 低危 / 2 高危（触发 HITL）/ 3 极危（物理闭环），持久化于 PostgreSQL |
| 审批工单（Ticket） | HITL 审批的持久化载体，含 Ticket UUID、状态机（待审批/已同意/已拒绝/超时）、审批人与意见，永久留存（ADR-05） |
| API Key | Agent 访问租户虚拟 MCP 端点的凭证，平台仅存哈希，支持权限范围、有效期与吊销 |
| 配额 | 租户资源上限（设备数/调用量），超限拒绝并返回配额错误 |
| seam / feature flag | EE 企业功能经接口装配点挂载到 CE 之上，以特性开关控制（ADR-14） |
| 免审白名单 | 指定工具+参数范围+时间段的免审批规则；V1.0 明确不做 |
| 审计日志 | append-only 操作留痕，覆盖工具调用、审批决策、管理操作，留存不少于 180 天 |
| 设备类别 | A 类原生 MCP 设备（V1.5 接入）；B 类 SDK 桥接设备（V1.0 主支持，Legacy Bridge）；C 类遗留哑设备不直接支持（doc/07 第 2.1 节） |
| Valkey | Redis API 兼容的开源内存存储（BSD-3），替代 Redis 作为部署栈（ADR-13） |

## 2. 总体描述

### 2.1 产品定位

ADC 是 AI 原生设备编排与治理平台：设备能力经 MCP 工具化后聚合为租户级虚拟 MCP 端点，Agent 凭 API Key 调用，高危操作经 HITL 审批熔断。V1.0 主交付 ce/ 社区版（LGPL-3，单机与轻集群形态），ee/ 企业功能（管理控制台、多租户、审计中心）经 seam 装配与 feature flag 开关（FR-019），同源发布开源制品与 EE 商业许可制品。首发离散制造（CNC/PLC），中国+全球双主场。

### 2.2 运行环境假设

- 平台部署于中国大陆数据中心，V1.0 仅大陆区域（海外区域随 FR-023 于 V1.5 后启动）。
- 控制台支持 Chrome/Edge 最新两个大版本；时区统一为 Asia/Shanghai。
- 审批人手机可访问企业微信/钉钉并可点击审批卡片回调公网地址（私有化场景回调链路设计见 doc/03 开放问题 6）。
- B 类设备侧运行 core-sdk 边缘运行时（C 内核，ADR-08），具备出网能力（WSS 反向连接）。
- A 类原生 MCP 设备 V1.5 接入（FR-021）；V1.0 设备台账预留厂商/型号/MCP 端点字段。
- 免审调用依赖链路：设备 SDK（B 类）— WSS 隧道 — 网关数据面 — Valkey 路由 — Agent MCP 端点。

### 2.3 用户角色与权限矩阵

| 角色 | 职责定位 | 设备管理 | 工具与风险等级 | 审批工单中心 | 审计日志 | API Key | 租户与配额 | 监控看板 |
|------|---------|---------|--------------|-------------|---------|---------|-----------|---------|
| 平台运营 | 平台级管理员，管理所有租户 | 管理 | 管理 | 管理 | 全租户管理 | 管理 | 管理 | 查看 |
| IT 管理员 | 租户内管理员，纳管设备与凭证 | 管理 | 管理 | 查看 | 本租户查询导出 | 管理 | 无 | 查看 |
| 自动化负责人 | 车间主任/智能制造经理，可被指定为审批人 | 查看 | 只读 | 审批 | 本租户查看 | 查看 | 无 | 查看 |
| 工厂设备工程师 | 一线运维，可被指定为审批人 | 查看 | 只读 | 审批 | 本租户查看 | 无 | 无 | 查看 |
| Agent 开发者 | 开发 Agent 应用，管理自有 Key | 查看 | 只读 | 无 | 本人调用记录 | 管理本人 Key | 无 | 无 |

权限规则：菜单级 RBAC 按角色裁剪；所有操作产生审计记录；管理操作（管理/审批/导出）必须有审计留痕；只读与查看权限不可导出。

### 2.4 设计约束

- 开源分层：monorepo 三仓 core-sdk/（Apache-2.0）、ce/（LGPL-3）、ee/（源码可见商业许可）；V1.0 主交付 ce/；ce/ 可脱离 ee/ 独立构建（ADR-12/14）。
- 技术栈：Go 1.24+ 后端；Vue 3 + TypeScript + Vite + Element Plus 前端；PostgreSQL 16+；Valkey 8+（ADR-13）；NATS JetStream 于阶段 2（V1.5）引入（ADR-02），V1.0 集群路由使用 Valkey Pub/Sub。
- 安全基线：上线前 SEC-01~14 阻断级与严重级发现清零（doc/05 第 2.3/2.4 节）；全链路 TLS 1.2+；密钥零硬编码。
- i18n：V1.0 控制台中文首发；后端消息与错误码 i18n 就绪（go-i18n 词条化，英文语言包随发）；文档中英双语、社区英文优先（ADR-18）。
- 合规：V1.0 完成等保 2.0 三级差距分析，V1.5 前通过测评（NFR-005）；审计留存不低于 180 天。
- 审批形态：V1.0 仅单级审批；默认超时 5 分钟；免审白名单不做。

## 3. 功能需求规格（V1.0）

### 3.1 高危操作治理基线（跨 FR 统一规则）

| 编号 | 规则 | 来源 |
|------|------|------|
| HBR-1 | 工具未配置风险等级时按租户默认策略分配，默认等级为 2（先审后用） | FR-006 |
| HBR-2 | 风险等级不低于 2 的工具调用必须经 HITL 审批方可执行，拦截率 100% | FR-005、G3 |
| HBR-3 | 审批工单默认超时 5 分钟，超时按拒绝处理 | FR-005 |
| HBR-4 | 免审白名单（工具+参数范围+时间段）V1.0 不交付，V1.5 随 FR-007 全量交付 | doc/03 1.3 |
| HBR-5 | 风险等级下调（如 2 降至 0）需二次确认并写入审计日志 | FR-006 |
| HBR-6 | 风险判定不得依赖工具名关键字；验证用例：名为 stop 的工具等级配置为 0 时直接执行不触发 HITL | SEC-09 |

### 3.2 规格格式说明

每项 FR 按"功能描述 / 输入 / 处理 / 输出 / 业务规则"五要素展开，业务规则以 BR-<FR编号>-<序号> 编号供测试引用；"映射"列出关联 UC、SEC/ADR 与设计文档。

### 3.3 FR-001 设备反向接入隧道（WSS）

- 功能描述：B 类设备经 WSS 长连接反向接入网关，解决内网无公网 IP 寻址；连接建立后网关经 JSON-RPC 2.0 向设备下发 tools/list、tools/call。V1.5 起定位为 Legacy Bridge（ADR-15）。
- 输入：设备 TLS 升级请求（携带 FR-002 凭证）、心跳 Ping、tools/list 上报、单条消息（上限 512KB）。
- 处理：TLS 握手与 Origin 白名单校验（SEC-04）→ 凭证鉴权 → 会话建立与旧会话踢除（SEC-15）→ 路由注册与 TTL 续期（SEC-14）→ 心跳超时检测。
- 输出：连接建立确认；设备在线/离线事件；超限消息断开告警。
- 业务规则：
  - BR-001-01：连接建立后 5 秒内完成 tools/list 同步。
  - BR-001-02：网络闪断时 SDK 按指数退避自动重连（1 秒起步、上限 60 秒），重连成功重新注册工具。
  - BR-001-03：连续 60 秒未收到 Pong 判定离线，清理会话与路由，状态置 offline。
  - BR-001-04：单条消息超过 512KB 拒绝并断开连接，记录告警。
  - BR-001-05：同一设备重复连接时旧会话被替代，仅保留最新会话。
- 映射：UC-001/002；SEC-04/05/14/15；design/33。

### 3.4 FR-002 设备鉴权（Token/HMAC/mTLS）

- 功能描述：设备接入必须经 Token、HMAC 签名或 mTLS 证书三者之一鉴权；凭证由平台签发、可轮转、可吊销（ADR-04 方案 B 先行、mTLS 为终态）。
- 输入：设备凭证、请求时间戳与 nonce、吊销列表查询条件。
- 处理：凭证从数据库/KMS 加载（消除硬编码，SEC-03）→ HMAC 校验采用 HMAC(secret, deviceID+nonce+timestamp) → 时间窗校验 → nonce 缓存防重放 → 吊销检查。
- 输出：鉴权通过 / 403 鉴权失败事件（含设备码与失败原因）。
- 业务规则：
  - BR-002-01：时间戳漂移窗口 5 分钟，窗口外拒绝。
  - BR-002-02：已用 nonce 拒绝（防重放缓存有效期内）。
  - BR-002-03：mTLS 模式证书不在白名单或已吊销时拒绝 TLS 握手。
  - BR-002-04：凭证吊销后立即踢除已建立的旧连接。
  - BR-002-05：切换鉴权方式需管理员二次确认并审计；凭证不落盘、不写日志（NFR-004）。
- 映射：UC-002；SEC-03；ADR-04；design/32。

### 3.5 FR-003 设备工具动态发现与聚合

- 功能描述：设备上线上报工具目录，网关按"设备码__工具名"命名空间聚合为租户级虚拟 MCP 端点；设备离线工具自动摘除。
- 输入：tools/list（含 name、input_schema、annotations、x-adc 扩展含 schema_version）。
- 处理：schema 合法性校验 → 命名空间聚合 → 聚合缓存写入 → 工具描述多语言（设备英文源 + 平台覆盖层，ADR-18）→ 离线摘除。
- 输出：租户虚拟 MCP 端点 tools/list（分页）。
- 业务规则：
  - BR-003-01：设备上线 30 秒内其工具对 Agent 可见。
  - BR-003-02：input_schema 非法 JSON 时跳过该工具并告警，不影响其余注册。
  - BR-003-03：同名工具经命名空间保证全局唯一、互不覆盖。
  - BR-003-04：同一设备重复上报以最新为准；离线即摘除。
- 映射：UC-003；SEC-22/24；ADR-18；design/32。

### 3.6 FR-004 集群化工具路由

- 功能描述：多网关实例经共享存储路由跨节点 tools/call 请求；V1.0 使用 Valkey Pub/Sub（ADR-13），NATS JetStream 于阶段 2 替换（ADR-02）。
- 输入：跨节点 tools/call 请求（含租户、设备码、工具名、参数）。
- 处理：查询设备位置 → Pub/Sub 转发至持有节点 → 等待响应（投递超时 15 秒，重试一次）→ 结果回传。
- 输出：执行结果 / 超时错误 / "设备离线或不存在"业务错误。
- 业务规则：
  - BR-004-01：设备未在任何节点在线时返回"设备离线或不存在"。
  - BR-004-02：任一节点宕机，其余节点 90 秒内完成其设备状态清理。
  - BR-004-03：路由 TTL 在连接存续期间定期续期（SEC-14）；Valkey 主从切换期间请求重试一次。
  - BR-004-04：Valkey 启用 ACL 最小权限与 TLS（SEC-06）。
- 映射：UC-004；SEC-06/10/14；ADR-02/13；design/32。

### 3.7 FR-005 HITL 高危指令审批（生产化单级审批）

- 功能描述：风险等级不低于 2 的工具调用被拦截生成审批工单，经企微/钉钉卡片推送审批人；同意后执行、拒绝或超时拦截终止，结果回传 Agent。V1.0 为单级审批，多级审批入 EE/V1.5。
- 输入：被拦截的 tools/call 上下文；审批决策回调（同意/拒绝，带签名）。
- 处理：工单 PG 持久化（ADR-05，修复 SEC-08）→ 卡片推送（webhook 密钥经环境变量注入，SEC-13）→ 回调验签与 OAuth 身份（SEC-01）→ 状态机原子更新（CAS，防并发双判 SEC-11）→ 超时任务自动拒绝 → 唤醒挂起调用并回传结果。
- 输出：审批工单（Ticket UUID 与状态）；Agent 侧 BLOCKED_BY_HITL / 执行结果；审计记录（含真实审批人身份）。
- 业务规则：
  - BR-005-01：工单生成后 30 秒内完成卡片推送；推送失败重试 3 次并告警（SEC-18）。
  - BR-005-02：默认超时 5 分钟，超时按拒绝处理并回传 BLOCKED_BY_HITL（HBR-3）。
  - BR-005-03：回调签名校验失败或工单已处理时拒绝该回调并记录异常事件。
  - BR-005-04：工单一次性消费；过期工单审批被拒（SEC-11）。
  - BR-005-05：审批中设备离线，工单自动失效并通知 Agent。
  - BR-005-06：审批记录含真实审批人工号与审批意见，永久留存。
- 映射：UC-005/006；SEC-01/08/10/11/13/18；ADR-05；design/32。

### 3.8 FR-006 工具风险等级配置管理

- 功能描述：风险等级（0/1/2/3）作为设备工具的可配置属性持久化于 PostgreSQL，支持默认等级策略与工具级覆盖；彻底移除关键字硬编码判定（SEC-09）。
- 输入：管理员配置（工具、等级）、设备上报的建议等级（annotations 映射值）。
- 处理：配置持久化 → 策略分发（30 秒内生效）→ 网关拦截行为读取数据库等级 → 设备离线重连后以平台配置为准。
- 输出：生效风险等级；等级变更审计记录。
- 业务规则：
  - BR-006-01：未配置等级的工具按租户默认策略分配，默认等级 2（HBR-1）。
  - BR-006-02：配置保存后 30 秒内网关拦截行为按新等级生效。
  - BR-006-03：等级下调需二次确认并审计（HBR-5）。
  - BR-006-04：无关键字判定残留（HBR-6 验证用例）。
  - BR-006-05：风险判定引擎 V1.0 为规则表实现，阶段 2 迁移 OPA（ADR-07）保持接口兼容。
- 映射：UC-007；SEC-09；ADR-07；design/32。

### 3.9 FR-007 审批流策略配置（V1.0 单级子集）

- 功能描述：V1.0 交付单级审批的审批人绑定、推送渠道配置与超时参数；多级审批、免审白名单、超时升级策略标注 V1.5/EE 交付。
- 输入：审批人绑定（租户组织成员）、渠道配置（企微/钉钉 webhook）、超时参数（默认 5 分钟）。
- 处理：策略持久化 → 对新工单生效 → 策略变更在途工单不受影响。
- 输出：生效策略视图；策略变更审计。
- 业务规则：
  - BR-007-01：V1.0 仅支持单级审批；配置多级/免审入口在 V1.0 不提供（HBR-4）。
  - BR-007-02：审批人离职/不在岗兜底策略 V1.0 为固定备份审批人（多级升级策略 V1.5）。
  - BR-007-03：策略变更仅对新工单生效。
- 映射：UC-005/007；FR-006 为前置；design/32。

### 3.10 FR-008 租户与组织管理

- 功能描述：多租户体系：租户创建、配额（设备数/调用量）、组织成员与角色、数据强隔离；社区版为单租户自部署形态，多租户入 EE。
- 输入：租户创建/停用/删除请求、配额配置、成员与角色配置。
- 处理：命名空间生成 → 配额校验（接入与调用链路强制）→ RBAC 鉴权 → 数据隔离。
- 输出：租户命名空间；403/配额错误；租户事件。
- 业务规则：
  - BR-008-01：跨租户资源请求一律 403（租户上下文取自凭证而非请求头，SEC-02）。
  - BR-008-02：超设备数或调用量配额拒绝并返回明确配额错误。
  - BR-008-03：租户停用后其设备连接被踢下线、审批工单全部失效。
  - BR-008-04：删除租户需 7 天冷静期。
  - BR-008-05：租户/设备 ID 白名单字符集与长度上限校验（SEC-20）。
- 映射：UC-008/013；SEC-02/20；GAP-13；design/32。

### 3.11 FR-009 Agent API Key 管理

- 功能描述：Agent 开发者凭 API Key 访问租户虚拟 MCP 端点；Key 支持权限范围（允许的工具列表）、有效期、吊销与轮换；平台仅存哈希。
- 输入：Key 创建（名称、工具范围、有效期）、吊销、轮换请求。
- 处理：签发 → 哈希存储 → 请求校验（身份+租户绑定+范围）→ 审计记录 key_id/agent_id。
- 输出：完整 Key 仅创建时显示一次；401/403；熔断告警。
- 业务规则：
  - BR-009-01：范围外工具调用返回 403 并记录审计。
  - BR-009-02：吊销或过期 Key 调用返回 401。
  - BR-009-03：单 Key 1 分钟内 100 次失败触发熔断告警（SEC-12）。
  - BR-009-04：Key 轮换支持新旧并行 24 小时过渡期。
  - BR-009-05：细粒度范围、SSO 联动为 EE 能力；CE 提供基础签发/校验/吊销。
- 映射：UC-009；SEC-02/12；design/32。

### 3.12 FR-010 设备纳管与生命周期管理

- 功能描述：设备注册（选鉴权方式并签发凭证）、凭证查看/重置/吊销、状态管理（offline/online/error）、设备注销与冻结。
- 输入：注册信息（设备码、名称、类型、鉴权方式、厂商/型号预留字段）、生命周期操作（冻结/吊销/注销/凭证重置，含操作理由）。
- 处理：唯一性校验 → 凭证签发 → 状态机流转（心跳驱动，SEC-17）→ 事件记录。
- 输出：设备台账、凭证包下载、状态变更事件。
- 业务规则：
  - BR-010-01：设备码全局唯一；重置凭证需填写理由并计入审计。
  - BR-010-02：吊销凭证或冻结设备后现有连接断开、新连接拒绝、历史日志仍可查询。
  - BR-010-03：状态流转 offine/online/error 均产生事件；台账中在线状态与实际一致（SEC-17）。
  - BR-010-04：A 类设备字段（厂商/型号/MCP 端点）V1.0 预留，V1.5 随 FR-021 启用。
- 映射：UC-001；SEC-03/17；design/32。

### 3.13 FR-013 审计日志查询与导出

- 功能描述：审计中心按时间/租户/设备/Agent/工具/状态多条件查询，支持 CSV/JSON 导出；日志 append-only 不可改删；链路按 ADR-06 异步落库。
- 输入：组合查询条件、分页参数、导出请求。
- 处理：索引查询 → 分页返回 → 异步导出任务（超限时）。
- 输出：结果集；导出文件（含调用参数、响应、审批人、审批意见）。
- 业务规则：
  - BR-013-01：查询 3 秒内返回且分页完整。
  - BR-013-02：任何角色修改/删除审计日志的尝试被拒绝。
  - BR-013-03：单次导出上限 10 万条，超出走异步任务。
  - BR-013-04：响应负载超阈值截断并标注。
  - BR-013-05：审计记录含 tenant_id、trace_id、真实 agent_id 与审批人（SEC-07/21）。
- 映射：UC-010；SEC-07/08；ADR-06；design/32。

### 3.14 FR-014 管理控制台

- 功能描述：B 端 Web 控制台（V1.0 中文首发）：设备管理、工具与风险等级、审批工单中心、审计日志、API Key、租户与配额、监控看板七大模块 + 登录 + 组织成员角色；菜单级 RBAC。
- 输入：用户登录、各模块操作。
- 处理：认证与会话 → RBAC 菜单裁剪 → 模块交互 → 操作审计与 30 秒内策略生效。
- 输出：七大模块界面与操作结果。
- 业务规则：
  - BR-014-01：用户仅可见本租户数据，菜单按角色裁剪（2.3 矩阵）。
  - BR-014-02：控制台配置操作 30 秒内网关行为生效且产生审计记录。
  - BR-014-03：时区统一 Asia/Shanghai；并发编辑同一配置以最后写入为准并提示。
  - BR-014-04：V1.0 监控看板展示基础指标（在线设备、连接数、调用量、审批推送成功率），告警通道与自定义阈值随 FR-017 于 V1.5 交付。
- 映射：UC-007/008/009/010/013；GAP-01；design/33。

### 3.15 FR-018 开源工程化与发布

- 功能描述：monorepo 三分层（core-sdk/ce/ee），补齐 LICENSE/NOTICE/CONTRIBUTING/SECURITY.md，DCO 提交机器人，CI 内置许可证扫描与 SBOM 生成，月度发布开源制品与 EE 制品。
- 输入：代码提交、PR、发布请求。
- 处理：三仓独立构建验证（ADR-12）→ DCO 门禁 → 许可证扫描（licensecheck/ScanCode）→ SBOM 生成（SPDX/CycloneDX）→ 发布制品。
- 输出：core-sdk/ce 开源制品、EE 商业许可制品、SBOM、版本兼容矩阵。
- 业务规则：
  - BR-018-01：许可证扫描零高危项，发现高危依赖阻断合并。
  - BR-018-02：PR 缺少 DCO 签名被 CI 拦截（DCO 机器人不可用时保持阻断）。
  - BR-018-03：公开仓库导出前完成敏感信息清理（gitleaks 门禁，SEC-25）。
  - BR-018-04：CE 与 EE 同 tag 发布，兼容矩阵可查询。
- 映射：UC-014；ADR-12/13；doc/05 第 7 章。

### 3.16 FR-019 企业功能开关与版本切分

- 功能描述：EE 功能经 seam 接口装配到 CE 之上，以 feature flag 控制；CE 可脱离 EE 独立构建运行，EE 可插拔激活。
- 输入：feature flag 配置、EE 模块装配。
- 处理：接口注册（ADR-14）→ 独立构建矩阵 → flag 一致性检查。
- 输出：CE 独立制品；EE 完整制品；flag 状态。
- 业务规则：
  - BR-019-01：仅检出 CE 代码时构建与测试全通过且不含任何 EE 代码。
  - BR-019-02：开启企业 flag 后控制台、审计中心、多级审批（V1.5）等 EE 功能可用。
  - BR-019-03：关闭某企业 flag 时该功能降级为社区版行为，不影响核心链路。
  - BR-019-04：EE 模块误引用 CE 内部实现时 CI 报错；flag 漂移发布前一致性检查。
- 映射：UC-014；ADR-14。

### 3.17 FR-020 开源文档站与示例工程

- 功能描述：CE 文档站（快速开始、API 文档、架构说明）+ 示例 Agent 与硬件示例工程，覆盖"克隆、构建、跑通第一条设备 MCP 调用"路径；文档中英双语。
- 输入：文档源、示例工程代码。
- 处理：站点构建与版本标注 → 示例随核心版本同步更新。
- 输出：文档站；可运行的示例 Agent 与硬件示例。
- 业务规则：
  - BR-020-01：开发者按快速开始 1 小时内完成设备接入并跑通一次 Agent 工具调用。
  - BR-020-02：API 文档支持按接口与版本检索并附请求响应示例。
  - BR-020-03：文档与当前版本不一致时标注版本号并提示过期。
- 映射：UC-014；ADR-18。

## 4. 用例规格说明

### UC-001 设备纳管注册

- 参与者：IT 管理员、平台运营。
- 前置条件：管理员已登录控制台且具备设备管理权限；租户配额未满。
- 主流程：1. 管理员进入设备管理，填写设备码/名称/类型/鉴权方式；2. 系统校验设备码唯一性；3. 签发凭证并生成凭证包；4. 设备入台账（状态 offline）；5. 操作写入审计日志。
- 备选流程：凭证包丢失时管理员提交重置理由后重新签发（旧凭证即时失效）。
- 异常流程：设备码重复则提示并拒绝；超配额返回配额错误。
- 后置条件：设备可携带凭证发起接入（UC-002）；审计记录含操作人与理由。
- 对应 FR：FR-010、FR-002。

### UC-002 设备接入鉴权

- 参与者：设备运行时（B 类 SDK）、网关系统。
- 前置条件：设备已完成 UC-001 注册且凭证有效。
- 主流程：1. 设备发起 TLS WSS 升级请求并携带凭证与签名；2. 网关校验 Origin 白名单、凭证、时间窗与 nonce；3. 建立会话并踢除旧会话；4. 注册路由并启动心跳；5. 5 秒内同步 tools/list。
- 备选流程：mTLS 模式设备经证书握手接入。
- 异常流程：凭证无效返回 403 并记录事件；吊销凭证的在线设备被踢下线；心跳 60 秒超时判定离线并清理路由。
- 后置条件：设备状态 online，工具进入聚合视图。
- 对应 FR：FR-001、FR-002。

### UC-003 工具聚合查询

- 参与者：Agent（经 API Key 认证）。
- 前置条件：设备已上线并完成工具上报。
- 主流程：1. Agent 调用租户虚拟 MCP 端点 tools/list；2. 网关按租户与 Key 权限范围聚合在线设备工具；3. 返回"设备码__工具名"命名空间工具清单（含风险等级与 schema）。
- 备选流程：离线设备工具自动不出现；非法 schema 工具被跳过。
- 异常流程：Key 无效返回 401；查询超时返回标准错误码。
- 后置条件：Agent 获得可调用工具视图。
- 对应 FR：FR-003。

### UC-004 Agent 调用免审工具

- 参与者：Agent、设备运行时。
- 前置条件：工具风险等级低于 2（0/1）且在 Key 权限范围内。
- 主流程：1. Agent 调用 tools/call；2. 网关校验 Key 与租户绑定；3. 风险判定为免审；4. 路由至设备持有节点执行；5. 结果回传 Agent；6. 审计异步落库（含 trace_id）。
- 备选流程：设备连接在其他节点时经 Valkey Pub/Sub 转发（FR-004）。
- 异常流程：设备离线返回"设备离线或不存在"；投递 15 秒超时重试一次后返回超时错误。
- 后置条件：调用记录可经 UC-010 查询。
- 对应 FR：FR-004、FR-003、FR-009。

### UC-005 高危调用 HITL 审批

- 参与者：Agent、自动化负责人/工厂设备工程师（审批人）、网关系统。
- 前置条件：工具风险等级不低于 2；审批人已绑定（FR-007）。
- 主流程：1. Agent 调用高危工具；2. 网关拦截并生成审批工单（PG 持久化）；3. 30 秒内向审批人推送企微/钉钉卡片（含签名回调链接）；4. 等待决策。
- 备选流程：卡片推送失败重试 3 次并告警后进入超时兜底。
- 异常流程：审批中设备离线则工单自动失效并通知 Agent；审批人未在有效期内响应则 5 分钟超时按拒绝处理。
- 后置条件：工单进入待审批状态，Agent 收到挂起语义；工单与结果永久留痕。
- 对应 FR：FR-005、FR-006、FR-007。

### UC-006 审批回调（同意/拒绝/超时）

- 参与者：审批人、网关系统、Agent。
- 前置条件：工单处于待审批状态且未过期。
- 主流程（同意）：1. 审批人点击同意并完成 OAuth 身份确认；2. 网关校验回调签名与工单状态（CAS 原子更新）；3. 指令下发执行；4. 结果回传 Agent；5. 审计记录审批人工号与意见。
- 备选流程（拒绝）：指令不执行，Agent 收到 BLOCKED_BY_HITL。
- 异常流程（超时）：5 分钟未决策按拒绝处理；签名校验失败或工单已处理则拒绝该回调并记录异常事件；并发双回调仅一个生效。
- 后置条件：工单状态终态化；审批决策不可抵赖。
- 对应 FR：FR-005。

### UC-007 工具风险等级配置

- 参与者：IT 管理员、平台运营。
- 前置条件：管理员具备工具与风险等级模块权限。
- 主流程：1. 选择设备工具并设置等级（0-3）；2. 保存（等级下调需二次确认）；3. 30 秒内网关拦截行为生效；4. 变更写入审计。
- 备选流程：未配置等级的工具按租户默认策略分配（默认 2，先审后用）。
- 异常流程：设备离线期间配置仍持久化，重连后以平台配置为准。
- 后置条件：拦截行为与配置一致；验证用例：名为 stop 等级 0 的工具直接执行（无关键字残留）。
- 对应 FR：FR-006。

### UC-008 租户与角色管理

- 参与者：平台运营。
- 前置条件：运营登录且具备租户与配额模块权限。
- 主流程：1. 创建租户并配置配额（设备数/调用量）；2. 添加组织成员并分配角色；3. 成员登录后按角色裁剪菜单；4. 操作留痕。
- 备选流程：停用租户时踢下线全部设备并失效全部工单。
- 异常流程：跨租户访问一律 403；超配额调用返回配额错误；删除租户进入 7 天冷静期。
- 后置条件：租户命名空间隔离生效。
- 对应 FR：FR-008。

### UC-009 API Key 管理

- 参与者：Agent 开发者、IT 管理员。
- 前置条件：开发者已加入租户。
- 主流程：1. 创建 Key（名称、工具范围、有效期）；2. 完整 Key 仅显示一次；3. 调用校验身份、租户绑定与范围；4. 审计记录 key_id/agent_id。
- 备选流程：Key 轮换时新旧并行 24 小时。
- 异常流程：范围外调用 403；吊销/过期调用 401；1 分钟 100 次失败触发熔断告警。
- 后置条件：Key 哈希落库，可随时吊销。
- 对应 FR：FR-009。

### UC-010 审计日志查询导出

- 参与者：IT 管理员、平台运营、审计相关角色。
- 前置条件：登录且具备审计日志模块权限。
- 主流程：1. 按时间/租户/设备/Agent/工具/状态组合查询；2. 3 秒内分页返回；3. 导出 CSV/JSON（含调用参数、审批人、审批意见）。
- 备选流程：单次导出超 10 万条走异步任务并通知完成。
- 异常流程：修改/删除日志操作被拒绝；响应超阈值截断并标注。
- 后置条件：导出文件可用于举证；操作本身留痕。
- 对应 FR：FR-013。

### UC-011 设备批量纳管（版本标注：V1.5）

- 参与者：IT 管理员。
- 前置条件：V1.5 版本；管理员具备设备管理权限。
- 主流程：1. 导入 CSV（设备码/名称/类型/鉴权方式，单文件上限 1000 行）；2. 系统异步批量创建并显示进度；3. 失败行给出逐行原因；4. 凭证包批量下载。
- 备选流程：创建分组后按组查询聚合工具与配置审批策略。
- 异常流程：重复设备码整行回滚；导入中断可续传。
- 后置条件：产线级设备在小时级完成纳管。
- 对应 FR：FR-011。

### UC-012 监控告警

- 参与者：平台运营、IT 管理员。
- 前置条件：登录控制台；V1.0 为基础看板范围。
- 主流程（V1.0）：1. 进入监控看板；2. 查看在线设备数、连接数、调用量、审批卡片推送成功率等基础指标（Prometheus 来源）。
- 备选流程（V1.5）：配置 CPU/内存/连接数阈值，超阈值 1 分钟告警；/healthz 连续 3 次失败从负载均衡摘除并告警；告警风暴聚合去重。
- 异常流程：指标缺失时显示数据源异常提示。
- 后置条件：SLA 指标可观测（NFR-006）。
- 对应 FR：FR-017（告警部分 V1.5）、FR-014。

### UC-013 登录与权限

- 参与者：全部五类角色。
- 前置条件：账号已由平台运营/IT 管理员创建并分配角色。
- 主流程：1. 用户名密码登录；2. 会话建立；3. 菜单按角色裁剪；4. 访问本租户数据。
- 备选流程：审批人等移动端角色经企微/钉钉 OAuth 免密进入审批卡片（FR-005 通道）。
- 异常流程：密码错误次数超限锁定并告警；会话超时自动登出。
- 后置条件：操作主体可追溯至真实账号。
- 对应 FR：FR-008、FR-014。

### UC-014 开源工程与发布

- 参与者：社区开发者、平台研发方。
- 前置条件：仓库三仓分层完成（ADR-12）。
- 主流程：1. 开发者克隆 ce/ 仓库，阅读 LICENSE/NOTICE 明确三层许可；2. 提交 PR（DCO 签名）经 CI 门禁（构建、govulncheck、许可证扫描、SBOM）；3. 合并后按月发布同 tag 的开源制品与 EE 制品；4. 开发者按文档站快速开始 1 小时内跑通设备接入与 Agent 调用。
- 备选流程：仅检出 CE 独立构建运行（不含 EE 代码）；部署 EE 制品开启 flag 激活企业功能。
- 异常流程：许可证扫描高危项阻断合并；DCO 缺失拦截并提示补签；密钥扫描命中阻断提交。
- 后置条件：发布物含 SBOM 与版本兼容矩阵。
- 对应 FR：FR-018、FR-019、FR-020。

## 8. 验收准则（V1.0 发布标准）

依据 doc/03 第 6 节 V1.0 发布标准逐条展开：

1. 种子试点：2 家离散制造种子工厂试点运行 4 周，无 P0/P1 缺陷（P0 阻断上线、P1 核心链路不可用）。
2. 设备在线率：试点期间在线率不低于 99%（在线时长除以应在线时长，工作日口径）。
3. 高危拦截率：风险等级不低于 2 的工具调用 HITL 拦截率 100%（含"改工具名绕过"回归用例，HBR-6）。
4. 等保差距分析：完成等保 2.0 三级差距分析报告，输出整改清单（测评通过为 V1.5 标准）。
5. 审计留存：审计日志留存 180 天验证通过（抽样时间跨度覆盖 180 天，append-only 复核通过）。
6. 开源发布：开源仓库公开（core-sdk Apache-2.0、ce LGPL-3），CI 门禁（构建、govulncheck、许可证扫描、SBOM、gitleaks）全部通过，文档站上线且快速开始 1 小时内跑通。
7. 安全前置：SEC-01~14 阻断级与严重级发现清零（doc/05 第 2.3 节），渗透测试报告无高危项。
8. NFR 达标：NFR-001/003/004/006 指标全部通过第 6 节验收测试方法；NFR-002 按 1000 台验证通过。
