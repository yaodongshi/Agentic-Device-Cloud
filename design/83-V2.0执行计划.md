## 二、V2.0 任务拆解（细粒度）

### C1 协议适配器生态（核心，16 人日）
- C1.1 适配器插件框架：Adapter 接口（Discover/Capabilities/Read/Write/CallTool）+ 注册表 + 独立进程模式（Go plugin 备选）；ce/internal/adapters/
- C1.2 Modbus TCP/RTU 适配器（自实现或 goburrow/modbus）+ 模拟器测试套件
- C1.3 OPC-UA 适配器（gopcua 库）+ 模拟服务器测试
- C1.4 FANUC FOCAS / Siemens 840D 适配器（依赖厂商 SDK，接口占位+文档；真实联调与厂商合作线下）
- C1.5 适配器注册表 API + 控制台"协议适配器"页（列表/启用/健康状态）
- C1.6 适配器认证测试套件（每个协议一组标准测试：发现/读/写/风险映射）

### C2 OEM 白标与 SDK 生态（8 人日）
- C2.1 ee/ 白标模块骨架（品牌替换 seam：控制台 title/logo/色板经配置注入）
- C2.2 SDK 认证计划（兼容矩阵自动验证脚本：SDK 版本×网关版本 CI 矩阵）
- C2.3 ESP32 C 内核完整版（承接 core-sdk/c/adc_edge.h 契约：WSS+TLS mbedTLS+JSON+OTA A/B——与硬件伙伴联合，代码骨架先行）

### C3 工具市场与开发者平台（8 人日）
- C3.1 工具包模型（adc_tool_packages 表：名称/版本/工具清单/签名）+ 发布/安装 API
- C3.2 市场页（控制台：浏览/搜索/安装/卸载）
- C3.3 开发者门户骨架（应用注册/A2A 编排器自助接入文档）

### C4-C5 平台化补全（10 人日）
- C4.1 OIDC 登录（adminauth seam 实装：authorization code flow + 用户自动映射）
- C5.1 预算预警（租户月度预算线 + 80%/100% 告警）
- C5.2 参数级校验（工具参数白名单/范围限制，执行前拦截）
- C5.3 社区翻译流水线（docs 站 i18n 贡献流程）
- C5.4 月度发布纪律（CHANGELOG 自动化 + release 检查清单进 CI）
