# ADC V2.2 M9 运行时韧性与权限闭环验收报告

> OpenSpec：`v2-2-runtime-resilience`
> 验收日期：2026-08-26
> 验收环境：macOS Docker Desktop，Compose 项目 `adc`，隔离 PostgreSQL 16 集成库
> 结论：本地工程验收通过；未创建或推送正式版本 tag

## 一、阶段目标

M9 关闭 M8 之后仍可在代码仓和本地环境完成的运行时风险：默认 seed 固定凭证、Python Agent 匿名路由、机器应用自批 HITL、会话授权陈旧、A2A 任务进程内存主存、参数 Guard 运行态缺口以及构建输入可变。真实客户 IdP、工业硬件、原生双架构主机和正式发布不在本阶段范围。

| 能力 | 验收证据 | 结果 |

## 七、残余边界

1. 未执行真实客户 IdP 的私有 CA、MFA claim、JWKS 轮换和 IdP 侧全局注销。
2. 未执行真实工业设备、厂商 SDK、amd64/arm64 原生 Linux和断网客户环境验收。
3. A2A 批准后保持 `working`，真实执行器回写 `completed/failed` 属下一阶段；本阶段禁止伪造完成。
4. PostgreSQL 是 A2A 权威状态，本阶段未引入 JetStream/outbox；阶段 2 消息通道应保持“PG 主存、消息通知”的架构边界。
5. 未创建 `v0.4.0` 或其他新 tag，未触发正式 Release workflow。

## 八、验收结论
