## 1. 设计目标与原则

### 1.1 目标用户

| 用户角色 | 主要使用端 | 核心任务 | 频率 |
|---------|-----------|---------|------|
| 工厂设备工程师（一线运维/保全） | 移动端（企微/钉钉）为主，桌面为辅 | 审批高危操作卡片、查看设备状态 | 高频短时（每次小于 1 分钟） |
| 自动化/生产负责人（车间主任/智能制造经理） | 桌面 | 查看产线设备与调用概览、审批工单、调整风险策略 | 中频 |
| IT/平台管理员（工厂 IT/租户管理员） | 桌面 | 设备纳管、凭证管理、审计查询导出、成员与角色、风险等级配置 | 高频 |
| Agent 开发者 | 桌面 | 创建与轮换 API Key、查看工具清单与参数 schema、排查调用日志 | 中频 |
| 平台运营（平台方） | 桌面 | 租户创建、配额管控、全平台监控 | 低频 |

### 1.2 设计原则

1. **B 端效率优先**：控制台是日常运营工具，不是营销页面。首屏即数据，不做大图横幅；高频任务（查设备、审工单、查日志）不超过 3 步；表格、批量操作、快捷键优先于图形化炫技。
2. **高危操作强确认**：凡涉及人身安全与设备损伤的操作（放行高危指令、风险等级下调、吊销凭证、冻结设备、停用 Key）必须二次确认，部分操作强制输入理由（10-200 字）；确认框明确写出后果，危险按钮统一红色。
3. **全链路可追溯展示**：一切操作可追"谁、何时、对什么、做了什么、结果如何"；关键对象（设备、工具、Key、工单）提供"查看审计"入口；trace_id 贯通设备接入、工具调用、HITL 工单与审计日志并在界面可查。
4. **状态可感知、反馈及时**：设备在线/离线、工单待审/超时、配额余量、渠道健康等状态使用统一色板与倒计时；同步操作 1 秒内反馈，异步任务（批量导入、大导出）给进度与完成通知。
5. **认知一致、组件统一**：同类操作在同类位置、用同类反馈；全部界面基于 Element Plus 组件体系，不自定义造轮子；术语与 PRD、技术文档统一（如"风险等级 0-3""审批工单""租户"）。

## 2. 信息架构

### 2.1 全局导航树

```text
ADC 控制台
├── 概览（登录后首页）
├── 设备管理
│   ├── 设备列表（含注册向导、批量导入）
│   └── 设备详情（从列表进入，含工具列表/凭证管理/审批与审计记录）
├── 工具与风险等级
│   └── 默认等级策略（页内设置区）
├── 审批
│   ├── 工单中心（列表，含待我审批视图）
│   ├── 工单详情（含审批操作区）
│   └── 审批策略配置（V1.0 单级：审批人映射、超时时间）
├── 审计日志
│   └── 详情抽屉（参数/响应/审批信息）
├── API Key
│   └── 创建/轮换/停用/吊销（页内弹窗）
├── 组织
│   ├── 组织成员与角色
│   └── 租户与配额（仅平台运营可见）
└── 监控看板
    └── 告警列表（页内）
```

侧栏固定 208px，可折叠为 64px 图标栏；顶栏含全局搜索（设备码/工单号/Key 名）、待审批徽标、消息通知、用户菜单（个人设置/退出）。

### 2.2 模块划分与角色可见性矩阵

权限级别：管（增删改配置）、批（审批等业务操作）、查（只读）、无（菜单隐藏）。

| 模块 | 设备工程师 | 生产负责人 | IT/平台管理员 | Agent 开发者 | 平台运营 |
|------|-----------|-----------|--------------|-------------|---------|
| 概览 | 查 | 查 | 查 | 查 | 查（全平台维度） |
| 设备管理 | 查 | 查 | 管 | 无 | 查 |
| 工具与风险等级 | 查 | 管 | 管 | 查 | 管（含默认策略） |
| 审批工单中心 | 批（分配给自己的） | 批+管策略 | 管 | 查 | 查 |
| 审计日志 | 查 | 查 | 管（含导出） | 查（仅自己 Key 相关） | 管（跨租户） |
| API Key | 无 | 无 | 管 | 管（自己创建的） | 无 |
| 组织成员与角色 | 无 | 查 | 管 | 无 | 管 |
| 租户与配额 | 无 | 无 | 查 | 无 | 管 |
| 监控看板 | 无 | 查 | 查 | 无 | 管（含告警配置） |

无权限模块在菜单与路由层双重隐藏，直接访问 URL 返回 403 页面。

## 3. 用户流程（核心流程 5 个）

### 3.1 设备纳管流程

```text
[管理员] 设备管理 -> 点击 [+ 注册设备]
    |
    v
填写设备信息: 设备码 / 名称 / 类型 / 鉴权方式(Token|HMAC|mTLS) / 分组(可选)
    |
    v
校验: 设备码格式与全局唯一? ---否---> 行内红字提示并回填
    |
    v 是
提交 -> 生成设备与凭证 -> 弹窗提示下载凭证包(凭证仅完整显示一次)
    |
    v
设备端配置凭证上线 -> 列表状态: 离线 -> 在线(心跳)
    |
    v
设备工具自动同步(30 秒内) -> 提示前往[工具与风险等级]确认等级
    |
    v
未配置工具默认等级 = 2(先审后用), 管理员可批量调整
```

### 3.2 高危操作审批流程（含企微卡片交互）

```text
[Agent] tools/call: CNC-003__stop
    |
    v
网关风险判定: 等级 3 >= 2 -> 拦截, 创建工单(持久化 PG)
    |
    v
30 秒内推送企微/钉钉模板卡片 -> [工程师手机] 查看参数摘要与剩余时间
    |
    +---> 点击 [同意执行] ---> 打开回调落地页(URL 带 HMAC 签名)
    |        |
    |        v
    |    落地页验签+校验工单状态(仅 PENDING 且未过期可处理)
    |        |
    |        +---> 通过: 显示"确认执行"按钮 -> 用户确认 -> 指令下发设备
    |        |        -> 落地页转成功态 -> Agent 收到执行结果
    |        |
    |        +---> 不通过(已处理/过期/签名失败): 落地页失败态 -> 记录异常审计
    |
    +---> 点击 [拒绝执行] ---> 回调落地页 -> 确认拒绝 -> 工单 REJECTED
    |        -> Agent 收到 BLOCKED_BY_HITL
    |
    v
5 分钟未处理 -> 工单超时 EXPIRED(自动拒绝) -> Agent 收到 BLOCKED_BY_HITL
```

关键决策点：卡片按钮不直接放行，统一跳转签名落地页做最终确认，杜绝按钮 URL 被转发或重放（对应 SEC-01/13 加固）。

### 3.3 风险等级配置流程

```text
[管理员] 工具与风险等级页 -> 搜索/筛选目标工具 -> 点击 [修改等级]
    |
    v
选择新等级(0 只读 / 1 低危 / 2 高危 / 3 极危)
    |
    +---> 上调(0/1 -> 2/3): 提示生效范围 -> 保存 -> 30 秒内网关按新等级拦截
    |
    +---> 下调(2/3 -> 0/1): 二次确认弹窗(后果说明) -> 必填操作理由(10-200 字)
              -> 确认 -> 写审计(含理由) -> 30 秒内生效
    |
    v
任何修改均可在审计日志中按"配置变更"类型检索
```

### 3.4 审计日志查询导出流程

```text
[审计员/管理员] 审计日志页
    |
    v
选择时间范围(必选, 默认近 24 小时, 最大跨度 31 天) + 组合筛选
(租户/设备/Agent/Key/工具/状态/trace_id 精确匹配)
    |
    v
[查询] -> 结果表格分页浏览 -> 行 [详情] 抽屉: 参数/响应/审批人/审批意见/免审依据/耗时
    |
    v
[导出 CSV] / [导出 JSON]
    |
    +---> 结果 <= 10 万条: 同步生成文件直接下载
    +---> 超过 10 万条: 创建异步导出任务 -> 顶部任务进度 -> 完成通知+下载链接
```

### 3.5 API Key 创建流程

```text
[Agent 开发者/管理员] API Key 页 -> 点击 [+ 创建 Key]
    |
    v
填写: 名称(必填, 租户内唯一) / 权限范围(允许的工具, 支持按设备码/分组/工具名通配)
/ 有效期(7 天|30 天|90 天|自定义|永久[仅管理员可选])
    |
    v
校验 -> 提交 -> 创建成功弹窗: 完整 Key 仅显示一次
    |
    v
[复制] 或 [下载] -> 列表仅显示前缀 ak_xxx**** 与最近调用时间
    |
    v
调用可追溯: 审计日志按 key_id 关联查询
```

### 4.5 工具与风险等级页（含等级修改二次确认弹窗）

## 5. 交互规范

### 5.1 表格规范

- 表格是控制台核心信息载体：默认紧凑模式（行高 40px，表头 40px 浅灰底 #F5F7FA）。
- 设备码、Key 前缀、trace_id、工单号一律等宽字体（见 6.3）。
- 首列多选框仅在有批量操作的表出现；操作列固定右侧；数字右对齐；长文本单行省略 + 悬停 Tooltip 全文。
- 状态表达双通道：色点/色 Tag + 文字（不单独依赖颜色）。
- 行操作不超过 3 个：主操作放按钮，其余收进"更多"下拉（防误触危险项放最远位置）。

### 5.2 筛选与分页规范

- 筛选区默认单行：条件不超过 4 个时平铺，超出折叠进"更多筛选"；时间范围类筛选必有默认值（近 24 小时），最大跨度 31 天，防止全表扫描。
- [查询]触发检索、[重置]恢复默认条件；筛选条件在翻页与刷新间保持；离开页面不记忆（回到默认），列表页内部 Tab 切换可记忆。
- 分页：每页 20（默认）/50/100；带跳页输入框与总数；总数超过 1 万显示"约 1 万+"；批量操作后原地刷新并保持筛选与页码（删除导致页码越界时自动回退最后一页）。

### 5.3 高危操作二次确认规范

- 适用范围：风险等级下调（2/3 降至 0/1）、同意放行高危工单（桌面端）、拒绝工单（需填原因）、吊销/重置设备凭证、冻结设备、停用/吊销 API Key、停用/删除租户、停用成员。
- 确认弹窗（MessageBox 定制）结构固定：标题陈述"动作+对象"（如"风险等级下调"）；正文写清后果（"该工具调用将不再触发 HITL 人工审批，直接执行"）；理由输入框（等级下调/吊销/冻结类必填，10-200 字，实时字数统计）；[取消]灰 + [确认(危险动词)]红；确认按钮文案必须含动作动词（"确认下调""确认吊销"），不用含糊的"确定"。
- 确认后全局 Message 反馈"操作已生效，30 秒内网关生效"（涉及网关行为时），并可在审计日志按"配置变更"检索到理由全文。
- 移动端卡片同意/拒绝：卡片本身不落最终决策，统一跳签名落地页确认，保证可抵赖性与防重放。

### 5.4 表单校验规范

- 触发时机：控件失焦即校验 + 提交时全量校验；错误提示在控件下方红字 12px，控件边框红色；提交失败时焦点自动定位到首个错误控件。
- 关键规则：设备码（字母数字与 - _，3-64 位，全局唯一）；理由文本（10-200 字）；JSON 参数（格式合法）；API Key 名称（租户内唯一，1-64 字）。
- 提交按钮在请求期间 loading 并禁用，防止重复提交；危险提交（吊销类）不设全局 loading 遮罩，仅按钮 loading。

### 5.5 loading 与骨架屏

- 列表首次加载：骨架屏（表头 + 5 行灰条，宽度模拟真实列宽）。
- 刷新/翻页/筛选：表格区域半透明遮罩 loading（不整页白屏）。
- 操作类：按钮内 loading；弹窗提交 loading 时禁止关闭。
- 异步任务（批量导入、10 万+导出）：顶部铃铛旁"任务中心"角标显示进度（百分比/行数），完成通知（站内+可选邮件），失败可重试。

### 5.6 空态与错误态规范

- 空数据态（真没有）：图标 + 主文案（"暂无设备"）+ 副文案引导（"注册第一台设备接入平台"）+ 主按钮（+ 注册设备）；无操作权限时去掉主按钮改文案"请联系租户管理员"。
- 筛选无结果态（有但没有匹配）：文案"未找到符合条件的结果" + [重置筛选]按钮，不与空数据态混淆。
- 错误态：加载失败卡片（图标 + 错误码 + [重试]）；权限不足独立 403 页；页面级异常统一"操作失败，请稍后重试"+ 错误码供技术支持定位。

- 图表库 ECharts 5（随前端打包，私有化离线可用）。
- 折线：时延/连接趋势，线宽 2px，主色 #2563EB；阈值线虚线 #DC2626；面积图在线设备数，主色 12% 透明度填充。
- 柱状：调用量 #2563EB、拦截量 #D97706 并列双色。
- 时间轴四档：近 1h / 24h / 7d / 30d；断点数据不连线（留白表中断）；tooltip 单位统一（ms/台/次/百分比一位小数）；图表无数据展示空态插画，不显示 0 轴欺骗。

### 6.7 图标规范

- 图标库 @element-plus/icons-vue，不自绘图标；默认 16px、内联 12px、空态插画 20px；线宽统一 1.5px。
- 实体映射固定：设备 Monitor、工具 Operation/SetUp、审批 Stamp、审计 Document、Key Key、租户 OfficeBuilding、成员 User、监控 DataLine。
- 状态点 8px 圆点（绿在线/灰离线/红异常/橙待处理），始终与文字标签同现。

不做。理由：V1.0 目标场景为工厂明亮办公环境与车间管理终端，暗色模式需全套 token 与图表配色适配，投入产出比低；列入 V1.5+ 随 i18n 窗口评估，本次仅保证色彩 token 语义化（为未来主题切换留接口）。

## 7. 响应式与多语言

### 7.1 响应式断点

| 断点 | 策略 |
|------|------|
| 1920 / 1440（优先） | 侧栏 208px + 内容区自适应；表格列全量展示 |
| 1280（下限） | 正常渲染；侧栏可折叠 64px；表格次要列可配置隐藏 |
| 1024-1280 | 侧栏强制折叠；表格横向滚动（固定首列与操作列）；弹窗宽度自适应 90% |
| 小于 1024（平板降级） | 只读优先：设备/工单/审计列表与详情可浏览；编辑类弹窗转全屏 Drawer；不承诺全部操作可用 |
| 移动端 | 仅审批回调落地页（375px 单列）与审批卡片；控制台其余页面显示"请在桌面端访问" |

### 7.2 i18n 预留策略（V1.0 中文首发，FR-023 于 V1.5 交付）

- 全部文案键值化，命名规范：`{模块}.{页面}.{区块}.{语义}`，示例：`device.list.title`、`hitl.card.remainTime`、`audit.export.asyncTask`；禁止硬编码中文，动态文案用占位符（`{0}`）而非拼接。
- 布局预留英文余量（1.5-1.8 倍宽度）：按钮最小宽度 88px（英文两词）；表单标签列宽按英文最长词估算；表头优先不换行，超宽 Tooltip；侧栏菜单名预留 1.5 倍字符宽。
- 日期时区：存储 UTC；V1.0 展示统一 Asia/Shanghai，格式 `YYYY-MM-DD HH:mm:ss`；审批卡片与落地页使用"绝对时间 + 相对时间"双轨（"超时时间 10:06:22，约 3 分钟后"）；V1.5 起按用户时区与区域格式本地化。
- 数字：千分位分隔；百分比保留一位小数；避免在文案中写死单位拼接。

## 8. 可访问性

- 对比度（WCAG AA）：正文不低于 4.5:1、大字与图标图形不低于 3:1；正文只用 #1F2329 与 #4B5563，禁用 #9CA3AF 作正文；风险等级 Tag 上文字用白色时确保与底色对比度达标（红 #DC2626 配白字约 4.6:1，橙 #D97706 配白字不足，橙 Tag 用深色文字 #7C3B00）。
- 键盘操作：全功能键盘可达；Tab 顺序等于视觉顺序；按钮 Enter/Space 激活、Esc 关闭弹窗并还原焦点、弹窗打开时焦点陷阱；焦点环 2px 主色清晰可见。
- 审批卡片可读性：正文不小于 16px（移动端）；参数摘要结构化换行而非整段 JSON；剩余时间倒计时每分钟更新、小于 1 分钟红色强调；同意/拒绝按钮并排大按钮、触控目标不小于 44x44 逻辑像素、双通道表达（文字+图标+颜色位置）；按钮跳转落地页确认，防止单次误触直接放行高危指令。
